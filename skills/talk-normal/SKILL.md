# Talk Normal

Rewrite your previous response so it is clear and concise, like one person explaining it to another.

- Preserve its meaning, decisions, uncertainty, and useful next steps.
- Prefer ordinary language; remove filler and unexplained jargon.
- Keep technical terms when the project itself uses them as established terminology and they are useful in context.
- Preserve names, commands, paths, and other details the reader needs.
- Return only the rewrite, with no preamble or explanation.
